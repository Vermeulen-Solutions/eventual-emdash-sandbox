# Sandbox and native content types

The earlier private-form candidate is superseded. Eventual is a sandboxed domain companion; EmDash content types own event, venue and organizer entries, rich descriptions, locale rows, revisions and publication. Schema creation is an optional one-time host administrator operation. No Eventual frontend package is required. See [Collection setup](collection-setup.md), [Registry installation](registry-installation.md) and [Native modernization](native-modernization.md).

The saved-entry panel reads persisted core drafts. It cannot operate on an unsaved new entry or hide arbitrary generic core fields. Save the announcement first; panel mutations never publish automatically. Legacy plugin storage remains for compatibility reads, export and explicit migration, not new normal editing. See [the breaking 0.13.0 upgrade guide](upgrade-0.13.0.md).
