# Eventual RSVP – Core 0.18.0 — new name, 21 admin languages and a sturdier public calendar

- **New name**: Eventual became **Eventual RSVP – Core**, part of the Eventual RSVP suite with Eventual RSVP – Registrations and Eventual RSVP – Tickets. The plugin ID stays `eventual`, so sites update in place and their routes, data and settings are unchanged. Admin texts point to the **Event settings** page.
- **Admin in 21 languages**: English, French, German, Dutch, Spanish, Italian, Portuguese (Portugal and Brazil), Polish, Czech, Swedish, Danish, Norwegian Bokmål, Finnish, Japanese, Simplified Chinese, Korean, Turkish, Ukrainian, Arabic and Hebrew, with right-to-left layout for Arabic and Hebrew. The admin follows the EmDash UI language. English is built in; the other languages are language packs from the `@vermeulen.solutions/eventual-locales` npm package, downloaded on first use, checked against a hash built into this release and kept in plugin storage. Table buttons and status badges in the events list and the dates panel are translated too.
- **New permission**: `network:request` to `cdn.jsdelivr.net`, only for those language packs. Administrators approve the plugin again when they update. Without network access the admin stays in English and tries again a few minutes later.
- **Busy months no longer break the public calendar**: the events feed and the calendar subscription asked EmDash for each event's web address separately, so about eight events in one range exceeded the sandbox's 10 calls and visitors saw "Events are temporarily unavailable". Core now asks once per language and builds the other addresses from the collection's URL pattern. Patterns with date placeholders are looked up one by one while calls remain; events past that are listed without a link instead of failing the feed.
- **Contacts**: `support@eventual.rsvp` and `security@eventual.rsvp`.
- **Compatibility**: EmDash `>=1.2.0 <2.0.0` (tested on EmDash 1.4.0). No schema changes and no new MCP tools.
