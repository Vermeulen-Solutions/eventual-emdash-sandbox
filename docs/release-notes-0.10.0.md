# Eventual 0.10.0

## Event list filters

- Filter events by publication status and by upcoming or past start dates.
- Keep the selected filters while paging through matching results.

## Safer editing

- Detect when another editor changes an event or venue while its form is open.
- Reload the latest version and ask the editor to review it before saving again.

## Site integration guidance

- Show the public JSON and iCalendar feed paths in Eventual Settings.
- Link to the Astro integration example from the settings page.

## Compatibility

This release keeps the Eventual 0.9.2 compatibility requirements and storage
format. It requires EmDash 1.0.1 or newer. No migration is required.
