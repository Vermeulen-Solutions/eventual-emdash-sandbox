# History and release evidence

The [0.14.0 acceptance record](../audit/releases/0.14.0/README.md) retains publication-time CIDs, checksums, verification and BBHC deployment evidence. Its figures and signed records describe that release, not a fresh build of today's documentation. Listing-documentation updates can change the profile CID while the versioned release remains unchanged.
