# Eventual registry artwork

Generated with the built-in imagegen tool on 2026-10-04. The icon and banner
share a forest-teal calendar mark, warm ivory background and coral event dot.
The banner adds the Eventual wordmark and a quiet calendar-grid motif.

Both PNGs are declared in `release.artifacts` in `emdash-plugin.jsonc` and are
uploaded as separate registry image blobs when a new release is published.
Keep them in this directory: a conventional root `icon.png` or `screenshots/`
directory would add image files to the size-limited installation archive.
No registry publication was performed as part of creating these assets.

## Final prompts

### Icon

Use case: logo-brand. Create a polished square registry icon for Eventual, an event management plugin for EmDash CMS. One distinctive, simple calendar mark with three stacked calendar rows subtly forming a lowercase e through negative space. Calm, confident and friendly, crisp flat graphic geometry, generous negative space, readable at 32px. Use a deep forest teal symbol on a warm ivory solid background, with one restrained warm coral event dot. Center the mark at roughly 64 percent of the square canvas. No lettering, no numbers, no border, no shadows, no gradients, no 3D, no mockup, no extra objects. Output one clean square icon suitable for a software plugin directory.

### Banner

Use case: ads-marketing / logo-brand. Generate a separate wide landscape software plugin registry banner for Eventual, approximately 3:1 aspect ratio. The attached icon is the identity reference: reproduce its deep forest teal calendar mark, warm ivory background and coral event dot faithfully; preserve the two binder tabs and three rounded horizontal ivory calendar rows. Put that same mark at modest scale in the left portion of the wide banner, and the exact word 'Eventual' prominently beside it in clean, bold, contemporary sans-serif lettering, deep forest teal. Text must read exactly 'Eventual', no other text or tagline. Generous whitespace, quiet warm ivory solid backdrop. Add a very subtle abstract calendar-grid rhythm at the far right, mostly negative space, with one small coral event dot. Keep the logo and word entirely within the central safe area with generous margins so they survive cropping. Crisp flat editorial brand graphic. No photograph, no mockup, no UI screenshot, no border, no gradients, no shadows, no 3D, no additional words. One cohesive, understated banner that clearly belongs to the attached icon.
